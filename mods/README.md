# External Mod Paks

This directory previously contained `.pak` files tracked via git LFS.

Mod paks are now hosted at `https://www.aseanmotorclub.com/releases/mods/` and
downloaded at runtime by `mods.nix`. See the [mtdedimod-deploy skill](../../../.agents/skills/mtdedimod-deploy/SKILL.md#external-mod-paks) for upload instructions.
